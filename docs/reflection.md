# Reflection

During this assignment, I used an AI coding assistant
to develop a Student Expense Tracker CLI application
using Python. I experimented with Zero-shot, Few-shot,
and Chain-of-Thought prompting techniques.

Zero-shot prompting was useful for generating the basic
application structure and functions from clear instructions.
Few-shot prompting helped the AI follow a consistent
format by providing examples. Chain-of-Thought prompting
helped analyze edge cases, identify possible errors,
and generate unit tests.

Compared with GitHub Copilot, the AI coding assistant
used in this assignment provided a different interaction
experience. It was useful for generating code and
understanding implementation ideas through prompts.
However, the generated code required reviewing and
checking to ensure that it met the requirements.

I learned that prompt engineering significantly affects
the quality of AI-generated code. Clear instructions,
examples, and detailed problem descriptions can improve
the output. I also understood that AI-generated code
should not be blindly accepted. Developers must review,
test, and validate the code before using it.

Overall, this assignment improved my understanding
of prompt engineering and the practical use of AI
coding assistants in software development.
